## 1. Introduction to Dataset
### Key Terms
Dataset: A collection of records organized in rows and columns (table form).

Instance: A single row of data (one observation).

Feature: A single column of data (attribute of an instance). Features can be:
- Inputs to a model (predictors)
- Outputs to be predicted (targets)

Data Type: A feature can be real, integer, categorical, ordinal, string, date,
or time. Traditional ML typically uses real or categorical values.

Common dataset splits:
- Training dataset: Used to train the model.
- Testing (validation) dataset: Used to evaluate the model.

Data representation in a table is the most common format for analysis and helps
to identify data issues quickly.

### b) Data Normalization (Min-Max Scaling)
Data normalization makes numeric features comparable by putting them on a common
scale. This prevents features with large ranges from dominating distance-based or
gradient-based models and improves training stability.

Min-max scaling is a normalization technique that linearly rescales each numeric
feature to a fixed range (usually 0 to 1). For each value $x$, the transformed
value is computed using:

$$
x' = \frac{x - \min(x)}{\max(x) - \min(x)}
$$

After scaling, the minimum value of a feature becomes 0 and the maximum becomes 1,
with all other values mapped proportionally in between.

Steps:
```python
from sklearn import preprocessing

min_max_scaler = preprocessing.MinMaxScaler()
X = df.iloc[:, :4]
X_scaled = min_max_scaler.fit_transform(X)
df_normalized = pd.DataFrame(X_scaled)
```

## 8. Handling Categorical Variables
Categorical variables describe qualities and must be converted to numeric form for
machine learning.

### a) Label Encoding
Use when the category is ordinal or binary.

```python
from sklearn import preprocessing

label_encoder = preprocessing.LabelEncoder()
df["Species"] = label_encoder.fit_transform(df["Species"])
```

Limitation: Labels imply order (priority) even when none exists.

### b) One-Hot Encoding
Create one column per category.

```python
from sklearn import preprocessing

enc = preprocessing.OneHotEncoder()
enc_df = enc.fit_transform(df[["Species"]]).toarray()
```

Pros: no implied order. Cons: wider data (more columns).

### c) Dummy Variable Encoding
Create k-1 columns instead of k.

```python
one_hot_df = pd.get_dummies(df, prefix="Species", columns=["Species"], drop_first=True)
```

Pros: avoids dummy variable trap. Cons: drops one category reference.

3. What is the need of data normalization?

4. What are the different techniques for handling missing data?
	Sequence and when to use each technique:
	1) Inspect the pattern of missingness (random vs. systematic) and the
	   percentage missing per column/row. This guides the choice.
	2) Remove rows: Use when only a small number of rows are missing values and
	   deleting them does not bias the dataset (e.g., <5% missing and random).
	3) Remove columns: Use when a column has too many missing values (e.g., >40-60%)
	   and it is not critical for analysis.
	4) Simple imputation:
	   - Mean: Use for symmetric numeric data without outliers.
	   - Median: Use for numeric data with skew or outliers.
	   - Mode: Use for categorical variables.
	5) Forward fill / backward fill:
	   - Forward fill (ffill) carries the last observed value forward until a new
	     value appears. Use for time series where the signal changes slowly or is
	     piecewise constant (e.g., daily inventory levels, sensor readings).
	   - Backward fill (bfill) uses the next observed value to fill earlier gaps.
	     Use when later values are more reliable or when the measurement represents
	     a future-known state (e.g., corrected data loads).
	   - Caution: ffill/bfill can create long constant stretches that hide real
	     variability. Always consider the time gap size before filling.
	6) Model-based imputation:
	   - Idea: Predict missing values using other features that are correlated.
	   - Common methods: KNN imputation (uses similar rows), regression models, or
	     iterative imputation (models each feature in turn).
	   - Use when missingness is moderate to high and relationships among features
	     are strong enough to estimate the missing values.
	   - Trade-off: Better accuracy, but higher complexity and risk of overfitting.
	7) Validate impact:
	   - Compare summary stats (mean, median, variance) before vs. after.
	   - Check distributions and correlations for major shifts.
	   - If modeling, compare model performance with and without imputation.
	   - If results change drastically, revisit the imputation strategy.
