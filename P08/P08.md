## 3. Finding patterns of data
Patterns of data can be found out with the help of different types of plots.
Types of plots are:

### A. Distribution Plots
- Dist-Plot
- Joint Plot
- Rug Plot

### B. Categorical Plots
- Bar Plot
- Count Plot
- Box Plot
- Violin Plot

### C. Advanced Plots
- Strip Plot
- Swarm Plot

### D. Matrix Plots
- Heat Map
- Cluster Map

---

### A. Distribution Plots
These plots help us to visualise the distribution of data. We can use these plots to understand the mean, median, range, variance, deviation, etc of the data.

#### a. Distplot
- Dist plot gives us the histogram of the selected continuous variable.
- It is an example of a univariate analysis.
- We can change the number of bins i.e. number of vertical bars in a histogram.

```python
sns.distplot(dataset['age'], bins=10)
```
*Note: To remove the kernel density estimation (KDE) line, you can pass `kde=False`.*

#### b. Joint Plot
- It is the combination of the distplot of two variables.
- It is an example of bivariate analysis.
- We additionally obtain a scatter plot between the variables to reflect their linear relationship. We can customize the scatter plot into a hexagonal plot, where the more the color intensity, the more will be the number of observations.

#### c. The Rug Plot
The `rugplot()` is used to draw small bars along the x-axis for each point in the dataset.

---

### B. Categorical Plots
Categorical plots, as the name suggests, are normally used to plot categorical data. The categorical plots plot the values in the categorical column against another categorical column or a numeric column.

#### a. The Bar Plot
The `barplot()` is used to display the mean value for each value in a categorical column, against a numeric column.

```python
sns.barplot(x='sex', y='age', data=dataset)
```

In addition to finding the average, the bar plot can also be used to calculate other aggregate values for each category. To do so, you need to pass the aggregate function to the estimator. For instance, you can calculate the standard deviation for the age of each gender as follows:

```python
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns

sns.barplot(x='sex', y='age', data=dataset, estimator=np.std)
```

#### b. The Count Plot
The count plot is similar to the bar plot, however it displays the count of the categories in a specific column. For instance, if we want to count the number of males and women passenger we can do so using count plot as follows:

```python
sns.countplot(x='sex', data=dataset)
```

#### c. The Box Plot
The box plot is used to display the distribution of the categorical data in the form of quartiles. The centre of the box shows the median value. The value from the lower whisker to the bottom of the box shows the first quartile. From the bottom of the box to the middle of the box lies the second quartile. From the middle of the box to the top of the box lies the third quartile and finally from the top of the box to the top whisker lies the last quartile.

Now let's plot a box plot that displays the distribution for the age with respect to each gender.

```python
sns.boxplot(x='sex', y='age', data=dataset)
```

If there are any outliers or the passengers that do not belong to any of the quartiles, they are called outliers and are represented by dots on the box plot.

You can make your box plots more fancy by adding another layer of distribution using the hue parameter:

```python
sns.boxplot(x='sex', y='age', data=dataset, hue="survived")
```

#### d. The Violin Plot
The violin plot is similar to the box plot, however, the violin plot allows us to display all the components that actually correspond to the data point. The `violinplot()` function is used to plot the violin plot.

```python
sns.violinplot(x='sex', y='age', data=dataset)
```

Like box plots, you can also add another categorical variable to the violin plot using the hue parameter as shown below:

```python
sns.violinplot(x='sex', y='age', data=dataset, hue='survived')
```

---

### C. Advanced Plots

#### a. The Strip Plot
The strip plot draws a scatter plot where one of the variables is categorical. We have seen scatter plots in the joint plot and the pair plot sections where we had two numeric variables. The strip plot is different in a way that one of the variables is categorical in this case, and for each category in the categorical variable, you will see a scatter plot with respect to the numeric column.

The `stripplot()` function is used to plot the strip plot.

```python
sns.stripplot(x='sex', y='age', data=dataset, jitter=False)
```

You can see the scattered plots of age for both males and females. The data points look like strips. It is difficult to comprehend the distribution of data in this form. To better comprehend the data, pass True for the jitter parameter which adds some random noise to the data:

```python
sns.stripplot(x='sex', y='age', data=dataset, jitter=True)
```

Like violin and box plots, you can add an additional categorical column to strip plot using hue parameter:

```python
sns.stripplot(x='sex', y='age', data=dataset, jitter=True, hue='survived')
```

#### b. The Swarm Plot
The swarm plot is a combination of the strip and the violin plots. In the swarm plots, the points are adjusted in such a way that they don't overlap. Let's plot a swarm plot for the distribution of age against gender. 

```python
sns.swarmplot(x='sex', y='age', data=dataset)
```

Let's add another categorical column to the swarm plot using the hue parameter.

```python
sns.swarmplot(x='sex', y='age', data=dataset, hue='survived')
```

---

### D. Matrix Plots
Matrix plots are the type of plots that show data in the form of rows and columns. 

#### a. Heat Maps
Heat maps are normally used to plot correlations between numeric columns in the form of a matrix. To draw matrix plots, we need meaningful information on rows as well as columns. Calling the `corr()` method returns the correlation between all the numeric columns.

```python
corr = dataset.corr()
sns.heatmap(corr)
```

The correlation values can also be plotted on the heatmap by passing True for the annot parameter:

```python
sns.heatmap(corr, annot=True)
```

#### b. Cluster Map
In addition to the heat map, another commonly used matrix plot is the cluster map. The cluster map basically uses Hierarchical Clustering to cluster the rows and columns of the matrix.

## 7. Oral Questions (Viva)
1. **What is Seaborn?**
   *Answer:* Seaborn is a Python data visualization library based on Matplotlib that provides a simple interface for drawing attractive statistical plots.

2. **What is the difference between Univariate and Bivariate analysis?**
   *Answer:* Univariate analysis looks at only one variable at a time (e.g., distplot). Bivariate analysis looks at the relationship between two variables (e.g., jointplot).

3. **What is a Dist-Plot used for?**
   *Answer:* It creates a histogram of a continuous numerical variable to show its distribution.

4. **What is the difference between a Bar Plot and a Count Plot?**
   *Answer:* A Bar plot shows an average or calculated value (like mean). A Count plot simply counts the number of occurrences of each category.

5. **What does a Box Plot show?**
   *Answer:* It shows data distribution using quartiles (Q1, Q2/median, Q3) and whiskers. Dots outside the whiskers are outliers.

6. **How is a Violin Plot different from a Box Plot?**
   *Answer:* A Violin Plot combines a box plot with a density curve, showing the full distribution and peaks of the data, not just the quartiles.

7. **What is the difference between a Strip Plot and a Swarm Plot?**
   *Answer:* Both are scatter plots for categorical data. In a Strip Plot, points can overlap. In a Swarm Plot, points are carefully adjusted so they don't overlap at all.

8. **Why do we use a Heat Map?**
   *Answer:* A Heat Map visualizes matrix data using color gradients. It is most commonly used to show the correlation matrix between numerical columns.

9. **What does the `hue` parameter do?**
   *Answer:* It adds another categorical dimension to a plot by separating the data elements with different colors based on a specific column (e.g., coloring points by 'survived').

10. **What is a Cluster Map?**
    *Answer:* It is a matrix plot built on a Heat Map that also uses Hierarchical Clustering to automatically group similar rows and columns together.
