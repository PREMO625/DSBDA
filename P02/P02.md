## 2. Identification and Handling of Missing Values
Missing data can be None or NaN in pandas. Use the following functions:
- isnull(), notnull()
- dropna(), fillna(), replace()

### 2.1 Checking missing values
```python
import pandas as pd

df = pd.read_csv("StudentsPerformance.csv")
```

### 2.2 Filling missing values
```python
# Fill with a constant
df.fillna(0)

# Fill with mean/median/std/min/max
df["math score"] = df["math score"].fillna(df["math score"].mean())
df["math score"] = df["math score"].fillna(df["math score"].median())
df["math score"] = df["math score"].fillna(df["math score"].std())
df["math score"] = df["math score"].fillna(df["math score"].min())
df["math score"] = df["math score"].fillna(df["math score"].max())

# Replace NaN with a sentinel value
df.replace(to_replace=np.nan, value=-99)
```

### 2.3 Dropping missing values
```python
# Drop rows with any missing value
df.dropna()

# Drop rows where all values are missing
df.dropna(how="all")

# Drop columns with any missing value
df.dropna(axis=1)
```

## 3. Identification of Outliers
An outlier is a data point far from the rest of the observations. Outliers affect
mean and standard deviation more than the median.

### 3.1 Boxplot method
A boxplot summarizes a numeric column using quartiles. The box spans from Q1
(25th percentile) to Q3 (75th percentile) and the line inside the box is the
median. Whiskers typically extend to $1.5 * IQR$ from Q1 and Q3. Points beyond
the whiskers are flagged as outliers. This method is quick, visual, and robust
for univariate outlier detection.

```python
col = ["math score", "reading score", "writing score", "placement score"]
df.boxplot(col)

# Example: find extreme math scores
np.where(df["math score"] > 90)
```

### 3.2 Scatterplot method
A scatterplot is used for paired numeric variables to detect unusual
combinations. Points far from the general trend or far from the dense cluster
are potential outliers. This method is useful when you want to validate whether
two variables follow an expected relationship (for example, higher placement
score should imply more offers).

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(18, 10))
ax.scatter(df["placement score"], df["placement offer count"])
plt.show()

# Example: suspicious combinations
np.where((df["placement score"] < 50) & (df["placement offer count"] > 1))
np.where((df["placement score"] > 85) & (df["placement offer count"] < 3))
```

### 3.3 Z-score method
Z-score measures how many standard deviations a value is away from the mean:
$z = (x - mean) / std$. It is best for approximately normal distributions.
A common threshold is 3 (or 2.5 for stricter detection). Values with
$|z| > threshold$ are treated as outliers. It is sensitive to extreme values
because mean and standard deviation are affected by outliers.

```python
import numpy as np
from scipy import stats

z = np.abs(stats.zscore(df["math score"]))
threshold = 3
outliers = np.where(z > threshold)
```

### 3.4 IQR method
The IQR method is robust for skewed data. Compute Q1 and Q3, then
$IQR = Q3 - Q1$. Values below $Q1 - 1.5 * IQR$ or above
$Q3 + 1.5 * IQR$ are treated as outliers. This method does not assume a normal
distribution and works well for most real-world numeric data.

```python
sorted_rscore = sorted(df["reading score"])
q1 = np.percentile(sorted_rscore, 25)
q3 = np.percentile(sorted_rscore, 75)
iQR = q3 - q1

lower = q1 - 1.5 * iQR
upper = q3 + 1.5 * iQR

outliers = [x for x in sorted_rscore if x < lower or x > upper]
```

## 5. Data Transformation
Purpose:
- Change scale for better understanding
- Reduce skewness and make the distribution closer to normal

### 5.0 Common transformation methods (theory)
- Smoothing: reduces noise and highlights underlying patterns (e.g., moving
   average or binning). Used when data is noisy.
- Aggregation: combines data into summaries (e.g., daily to monthly totals).
   Useful for reducing detail and improving stability.
- Generalization: converts low-level values into higher-level categories
   (e.g., age 21 -> "young"). Makes patterns easier to interpret.
- Normalization: rescales numeric values to a common range or distribution
   (e.g., min-max or z-score). Helps fair comparisons across features.
- Feature construction: creates new variables from existing ones to improve
   interpretation or model performance (e.g., duration from join year).

### 5.1 Feature construction (scale change)
