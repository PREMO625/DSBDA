## 1. Logistic Regression
Logistic regression is a supervised learning algorithm used for classification.
It models the probability of a binary outcome (0 or 1) based on input features.

### 1.1 Core idea
A linear combination of inputs is passed through a sigmoid to produce a
probability:
$$
z = b_0 + b_1 x_1 + b_2 x_2 + ... + b_p x_p
$$
$$
\hat{p} = \sigma(z) = \frac{1}{1 + e^{-z}}
$$

Decision rule (binary):
$$
\hat{y} = \begin{cases}
1, & \hat{p} \ge 0.5 \\
0, & \hat{p} < 0.5
\end{cases}
$$

### 1.2 Why logistic regression is used
- Output is a probability between 0 and 1.
- Works well for binary classification.
- Baseline model for classification tasks.
- Interpretable coefficients (effect on log-odds).

### 1.3 Log-odds (logit) form
$$
\log\left(\frac{\hat{p}}{1 - \hat{p}}\right) = b_0 + b_1 x_1 + ... + b_p x_p
$$

Usage: shows how a unit change in $x_i$ affects the log-odds of the positive class.

-------------------------------------------------------------------------------

## 2. Linear vs Logistic Regression
- Linear regression predicts a continuous value (e.g., price, salary).
- Logistic regression predicts a probability and class label.
- Linear regression uses Ordinary Least Squares (OLS).
- Logistic regression uses Maximum Likelihood Estimation (MLE).

-------------------------------------------------------------------------------

## 3. Sigmoid (Logistic) Function
Definition:
$$
\sigma(z) = \frac{1}{1 + e^{-z}}
$$

Usage and importance:
- Maps any real number to (0, 1).
- Converts linear model output into probability.
- Enables classification with a threshold (usually 0.5).

-------------------------------------------------------------------------------

## 4. Types of Logistic Regression
1. Binary logistic regression: two classes (spam / not spam).
2. Multinomial logistic regression: three or more classes (no order).
3. Ordinal logistic regression: ordered classes (ratings 1 to 5).

## 5. Confusion Matrix and Evaluation Metrics
A confusion matrix compares predicted vs actual classes.

| Actual \ Predicted | Positive | Negative |
| --- | --- | --- |
| Positive | TP | FN |
| Negative | FP | TN |

Definitions:
- TP: True Positive (actual positive, predicted positive)
- TN: True Negative (actual negative, predicted negative)
- FP: False Positive (actual negative, predicted positive)
- FN: False Negative (actual positive, predicted negative)

### 5.1 Metrics (definitions, formulas, usage, importance)

Accuracy
- Definition: fraction of correct predictions.
- Formula:
  $$
  Accuracy = \frac{TP + TN}{TP + TN + FP + FN}
  $$
- Usage: overall correctness.
- Importance: simple, but can be misleading on imbalanced data.

Error Rate
- Definition: fraction of incorrect predictions.
- Formula:
  $$
  Error = \frac{FP + FN}{TP + TN + FP + FN} = 1 - Accuracy
  $$
- Usage: overall error rate.
- Importance: complements accuracy.

Precision
- Definition: correctness among predicted positives.
- Formula:
  $$
  Precision = \frac{TP}{TP + FP}
  $$
- Usage: when false positives are costly (e.g., spam filter).
- Importance: tells reliability of positive predictions.

Recall (Sensitivity)
- Definition: correctness among actual positives.
- Formula:
  $$
  Recall = \frac{TP}{TP + FN}
  $$
- Usage: when false negatives are costly (e.g., disease detection).
- Importance: tells how many real positives are captured.

F1-Score
- Definition: harmonic mean of precision and recall.
- Formula:
  $$
  F1 = \frac{2 \cdot Precision \cdot Recall}{Precision + Recall}
  $$
- Usage: when you need a balance between precision and recall.
- Importance: robust for imbalanced classes.

Specificity (True Negative Rate)
- Definition: correctness among actual negatives.
- Formula:
  $$
  Specificity = \frac{TN}{TN + FP}
  $$
- Usage: when false positives are costly.
- Importance: shows how well negatives are identified.

False Positive Rate (FPR)
- Definition: proportion of negatives incorrectly predicted as positive.
- Formula:
  $$
  FPR = \frac{FP}{FP + TN} = 1 - Specificity
  $$
- Usage: important in screening and spam filtering.
- Importance: lower FPR means fewer false alarms.

False Negative Rate (FNR)
- Definition: proportion of positives incorrectly predicted as negative.
- Formula:
  $$
  FNR = \frac{FN}{FN + TP} = 1 - Recall
  $$
- Usage: critical in medical and fraud detection.
- Importance: lower FNR means fewer missed positives.

Balanced Accuracy
- Definition: average of recall and specificity.
- Formula:
  $$
  Balanced\ Accuracy = \frac{Recall + Specificity}{2}
  $$
- Usage: preferred with class imbalance.
- Importance: accounts for both classes equally.

ROC-AUC (Area Under ROC Curve)
- Definition: probability the model ranks a random positive higher than a random negative.
- Usage: compares models across all thresholds.
- Importance: threshold-independent, good for imbalanced data.

## 6. Algorithm (Social Network Ads)
```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix, accuracy_score, precision_score, recall_score, f1_score

# Step 1: Load dataset
df = pd.read_csv("Social_Network_Ads.csv")

# Step 2: Preprocessing
# Convert categorical values if any (example)
# df["Gender"] = df["Gender"].map({"Male": 1, "Female": 0})

# Check missing values
print(df.isnull().sum())

# Split features and target
X = df.drop(["Purchased"], axis=1)
y = df["Purchased"]

# Train-test split
xtrain, xtest, ytrain, ytest = train_test_split(X, y, test_size=0.25, random_state=0)

# Feature scaling (important for logistic regression)
scaler = StandardScaler()
xtrain = scaler.fit_transform(xtrain)
xtest = scaler.transform(xtest)

# Step 3: Train model
logreg = LogisticRegression()
logreg.fit(xtrain, ytrain)

# Step 4: Predict
ypred = logreg.predict(xtest)

# Step 5: Metrics
cm = confusion_matrix(ytest, ypred)
print(cm)
print("Accuracy:", accuracy_score(ytest, ypred))
print("Precision:", precision_score(ytest, ypred))
print("Recall:", recall_score(ytest, ypred))
print("F1:", f1_score(ytest, ypred))
```
