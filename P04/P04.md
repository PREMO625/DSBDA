## 1. Linear Regression
Linear regression models the relationship between a dependent variable $y$ and one or
more independent variables $x$.

### 1.1 Simple (Univariate) Linear Regression
- One predictor variable.
- Model is a straight line.

Equation:
$$
\hat{y} = b_0 + b_1 x
$$
Where:
- $b_0$ is the intercept
- $b_1$ is the slope
- $\hat{y}$ is the predicted value

Error term:
$$
\varepsilon = y - \hat{y}
$$

### 1.2 Multiple (Multivariate) Linear Regression
- Two or more predictors.
- Model is a hyperplane.

Equation:
$$
\hat{y} = b_0 + b_1 x_1 + b_2 x_2 + ... + b_p x_p
$$

### 1.3 Polynomial Features (Optional Extension)
Transform features to capture curved relationships:
$$
\hat{y} = a + b x + c x^2
$$
Higher degree may cause overfitting.

-------------------------------------------------------------------------------

## 2. Least Squares Method
Least squares chooses $b_0$ and $b_1$ that minimize the total squared error.

Objective function:
$$
\min \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

Closed-form for simple linear regression:
$$
b_1 = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2}
$$
$$
b_0 = \bar{y} - b_1 \bar{x}
$$

-------------------------------------------------------------------------------

## 3. Measuring Performance
### 3.1 Sum of Squares
- Total Sum of Squares (SST): total variance in $y$.
$$
SST = \sum_{i=1}^{n} (y_i - \bar{y})^2
$$

- Sum of Squares Error (SSE): unexplained variance.
$$
SSE = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

- Sum of Squares Regression (SSR): explained variance.
$$
SSR = \sum_{i=1}^{n} (\hat{y}_i - \bar{y})^2
$$

Relation:
$$
SST = SSR + SSE
$$

### 3.2 MSE and RMSE
- Mean Squared Error:
$$
MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2
$$

- Root Mean Squared Error:
$$
RMSE = \sqrt{MSE}
$$

Lower MSE/RMSE means a better fit.

### 3.3 R-Squared ($R^2$)
Measures proportion of variance explained by the model.
$$
R^2 = \frac{SSR}{SST} = 1 - \frac{SSE}{SST}
$$

- $R^2$ close to 1: good fit.
- $R^2$ close to 0: poor fit.

### 3.4 Evaluation Metrics (Definition, Usage, Importance)
- SST (Total Sum of Squares)
   - Definition: Total variance of the actual values around the mean.
   - Usage: Baseline variability before modeling.
   - Importance: Shows how much variation exists to explain.

- SSR (Regression Sum of Squares)
   - Definition: Variance explained by the regression model.
   - Usage: Used in $R^2$ calculation to show explained variance.
   - Importance: Higher SSR indicates the model explains more of the data.

- SSE (Sum of Squared Errors)
   - Definition: Variance not explained by the model.
   - Usage: Core error measure in MSE/RMSE.
   - Importance: Lower SSE means better fit.

- MSE (Mean Squared Error)
   - Definition: Average of squared errors.
   - Usage: Compare models on the same dataset and scale.
   - Importance: Penalizes large errors more than small errors.

- RMSE (Root Mean Squared Error)
   - Definition: Square root of MSE, in original units.
   - Usage: Easier to interpret error magnitude in the target scale.
   - Importance: Directly tells average prediction error size.

- $R^2$ (Coefficient of Determination)
   - Definition: Fraction of variance explained by the model.
   - Usage: Goodness-of-fit measure between 0 and 1.
   - Importance: Quick summary of how well the model explains the target.

## 4. Worked Example (Manual)
Data for 5 students:

| Student | X (Std X score) | Y (Std XII score) |
| --- | --- | --- |
| 1 | 95 | 85 |
| 2 | 85 | 95 |
| 3 | 80 | 70 |
| 4 | 70 | 65 |
| 5 | 60 | 70 |

Compute:
- $\bar{x} = 78$
- $\bar{y} = 77$
- $\sum (x_i - \bar{x})^2 = 730$
- $\sum (x_i - \bar{x})(y_i - \bar{y}) = 470$

Slope and intercept:
$$
b_1 = 470/730 = 0.644
$$
$$
b_0 = 77 - 0.644 * 78 = 26.768
$$

Regression line:
$$
\hat{y} = 26.768 + 0.644 x
$$

Interpretation:
- For every 1 unit increase in $x$, $y$ increases by 0.644.
- If $x=0$, predicted $y$ is 26.768.

Prediction example:
$$
\hat{y} = 26.768 + 0.644 * 65 = 68.38
$$

## 5. Training and Testing Dataset
Machine learning model development has two phases:

### 5.1 Training Phase
- Model learns from training data.
- Training error ($E_{in}$): error on training data.

### 5.2 Testing Phase
- Model is evaluated on unseen test data.
- Testing error ($E_{out}$): error on test data.

### 5.3 Generalization
- Ability to perform well on unseen data.
- Goal: minimize generalization error.

## 6. Algorithm (Synthetic Dataset)
```python
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

x = np.array([95, 85, 80, 70, 60])
y = np.array([85, 95, 70, 65, 70])

# Fit line (degree 1)
model = np.polyfit(x, y, 1)

# Coefficients
print(model)  # [slope, intercept]

# Prediction function
predict = np.poly1d(model)
print(predict(65))

# Predict all points
y_pred = predict(x)

# R-squared
from sklearn.metrics import r2_score
print(r2_score(y, y_pred))

# Plot
y_line = model[1] + model[0] * x
plt.plot(x, y_line, c="r")
plt.scatter(x, y_pred)
plt.scatter(x, y, c="r")
plt.show()
```

## 7. Algorithm (Boston Housing Dataset)
```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

# Load dataset
from sklearn.datasets import load_boston
boston = load_boston()

# Create dataframe
data = pd.DataFrame(boston.data)
data.columns = boston.feature_names

# Add target
data["PRICE"] = boston.target

# Check missing values
print(data.isnull().sum())

# Split features and target
x = data.drop(["PRICE"], axis=1)
y = data["PRICE"]

# Train-test split
xtrain, xtest, ytrain, ytest = train_test_split(
    x, y, test_size=0.2, random_state=0
)

# Train model
lm = LinearRegression()
model = lm.fit(xtrain, ytrain)

# Predict
ytrain_pred = lm.predict(xtrain)
ytest_pred = lm.predict(xtest)

# Evaluate
print("Train MSE:", mean_squared_error(ytrain, ytrain_pred))
print("Test MSE:", mean_squared_error(ytest, ytest_pred))
print("Test R2:", r2_score(ytest, ytest_pred))

# Plot predictions
plt.scatter(ytrain, ytrain_pred, c="blue", marker="o", label="Training data")
plt.scatter(ytest, ytest_pred, c="lightgreen", marker="s", label="Test data")
plt.xlabel("True values")
plt.ylabel("Predicted")
plt.title("True value vs Predicted value")
plt.legend(loc="upper left")
plt.show()
```

## Oral Questions (Viva)
1. What is the linear regression equation?
   - $\hat{y} = b_0 + b_1 x$ (simple) or $\hat{y} = b_0 + \sum b_i x_i$ (multiple).

2. What do slope and intercept represent?
   - Slope is change in $y$ per unit $x$; intercept is $y$ when $x=0$.

3. Why use least squares?
   - It minimizes the total squared error between actual and predicted values.

4. Difference between SSE, SSR, and SST?
   - SSE is unexplained error, SSR is explained variance, SST is total variance.

5. What does $R^2$ indicate?
   - Fraction of variance explained; closer to 1 means better fit.

6. Why use RMSE instead of MSE sometimes?
   - RMSE is in original units, easier to interpret.

7. What is overfitting in polynomial regression?
   - High-degree curves fit noise and reduce generalization.

8. Why split data into train and test?
   - To estimate how model performs on unseen data.

9. What is generalization error?
   - Error on new, unseen data.

10. When is linear regression not suitable?
   - When relationship is strongly non-linear or assumptions are violated.
