## 1. Basic Concepts of Text Analytics
Text analytics (text mining) extracts patterns and insights from unstructured text.
- Text mining focuses on the text itself (words, frequency, length).
- NLP focuses on linguistic structure and meaning (POS, entities, sentiment).

Applications:
- Sentiment analysis
- Topic classification
- Spam detection
- Information retrieval

-------------------------------------------------------------------------------

## 2. Text Analysis Operations using NLTK
NLTK provides tools for tokenization, stemming, tagging, parsing, and more.

### 2.1 Tokenization
Break text into sentences or words.

- Sentence tokenization:
  `sent_tokenize()`
- Word tokenization:
  `word_tokenize()`

### 2.2 Stop Words Removal
Stop words are common words (is, the, a) that add little meaning.
Remove them to reduce noise.

### 2.3 Stemming
Stemming reduces words to a root form (may not be a real word).
Example: fishing, fished, fisher -> fish.

### 2.4 Lemmatization
Lemmatization reduces words to dictionary form (lemma) using context.
Example: studies -> study.

### 2.5 POS Tagging
POS (Part of Speech) tagging assigns grammatical labels to each word.
It helps understand word role and meaning in a sentence.

Common POS tags (Penn Treebank):
- NN: Noun, singular (dog)
- NNS: Noun, plural (dogs)
- NNP: Proper noun, singular (London)
- NNPS: Proper noun, plural (Indians)
- PRP: Personal pronoun (he, she, they)
- PRP$: Possessive pronoun (his, her, their)
- VB: Verb, base form (eat)
- VBD: Verb, past tense (ate)
- VBG: Verb, gerund/present participle (eating)
- VBN: Verb, past participle (eaten)
- VBP: Verb, non-3rd person singular present (eat)
- VBZ: Verb, 3rd person singular present (eats)
- JJ: Adjective (happy)
- JJR: Adjective, comparative (happier)
- JJS: Adjective, superlative (happiest)
- RB: Adverb (quickly)
- RBR: Adverb, comparative (faster)
- RBS: Adverb, superlative (fastest)
- DT: Determiner (the, a)
- IN: Preposition/subordinating conjunction (in, on, because)
- CC: Coordinating conjunction (and, but)
- CD: Cardinal number (one, 2024)
- TO: "to" (to go)
- MD: Modal (can, will)
- UH: Interjection (wow)
- WDT: Wh-determiner (which)
- WP: Wh-pronoun (who)
- WRB: Wh-adverb (where, when)

## 3. Text Analysis Model using TF-IDF
TF-IDF measures how important a word is to a document in a corpus.

### 3.1 Term Frequency (TF)
Frequency of word $w$ in document $d$.
$$
TF(w,d) = \frac{\text{count of } w \text{ in } d}{\text{total words in } d}
$$

### 3.2 Inverse Document Frequency (IDF)
Down-weights common words across the corpus.
$$
IDF(w) = \log\left(\frac{N}{df(w)}\right)
$$
Where:
- $N$ = total documents
- $df(w)$ = number of documents containing word $w$

### 3.3 TF-IDF
$$
TFIDF(w,d) = TF(w,d) \cdot IDF(w)
$$

Notes:
- Rare words get higher TF-IDF.
- Common words get lower TF-IDF.

Disadvantage:
- Cannot capture semantics (synonyms treated as different words).

## 4. Bag of Words (BoW)
BoW converts text into a vector of word counts. Word order is ignored.
- Simple and fast
- Loses grammar and context

## 5. Algorithms
### 5.1 Tokenization, Stop Words, Stemming, Lemmatization, POS
```python
import nltk
import re
from nltk.tokenize import sent_tokenize, word_tokenize
from nltk.corpus import stopwords
from nltk.stem import PorterStemmer, WordNetLemmatizer

nltk.download("punkt")
nltk.download("stopwords")
nltk.download("wordnet")
nltk.download("averaged_perceptron_tagger")

text = "Tokenization is the first step in text analytics."

# Sentence tokenization
print(sent_tokenize(text))

# Word tokenization
tokens = word_tokenize(text)
print(tokens)

# Stop words removal
stop_words = set(stopwords.words("english"))
clean = re.sub("[^a-zA-Z]", " ", text)
filtered = [w for w in word_tokenize(clean.lower()) if w not in stop_words]
print(filtered)

# Stemming
ps = PorterStemmer()
for w in ["wait", "waiting", "waited", "waits"]:
    print(ps.stem(w))

# Lemmatization
lemmatizer = WordNetLemmatizer()
for w in word_tokenize("studies studying cries cry"):
    print(lemmatizer.lemmatize(w))

# POS tagging
print(nltk.pos_tag(word_tokenize("The pink sweater fit her perfectly")))
```

### 5.2 TF-IDF Calculation (Manual)
```python
import math
import pandas as pd

# Documents
documentA = "Jupiter is the largest Planet"
documentB = "Mars is the fourth planet from the Sun"

# Bag of Words
bagA = documentA.lower().split()
bagB = documentB.lower().split()

# Vocabulary
vocab = set(bagA).union(set(bagB))

# Word counts
numA = dict.fromkeys(vocab, 0)
for w in bagA:
    numA[w] += 1
numB = dict.fromkeys(vocab, 0)
for w in bagB:
    numB[w] += 1

# TF
def computeTF(wordDict, bagOfWords):
    tf = {}
    total = len(bagOfWords)
    for word, count in wordDict.items():
        tf[word] = count / float(total)
    return tf

tfA = computeTF(numA, bagA)
tfB = computeTF(numB, bagB)

# IDF
def computeIDF(documents):
    N = len(documents)
    idf = dict.fromkeys(documents[0].keys(), 0)
    for doc in documents:
        for word, val in doc.items():
            if val > 0:
                idf[word] += 1
    for word, val in idf.items():
        idf[word] = math.log(N / float(val))
    return idf

idfs = computeIDF([numA, numB])

# TF-IDF
def computeTFIDF(tfBag, idfs):
    tfidf = {}
    for word, val in tfBag.items():
        tfidf[word] = val * idfs[word]
    return tfidf

tfidfA = computeTFIDF(tfA, idfs)
tfidfB = computeTFIDF(tfB, idfs)

print(pd.DataFrame([tfidfA, tfidfB]))
```
