## 1. Concepts Used in Naive Bayes Classifier
### 1.1 Bayes Theorem
For events $A$ and $B$:
$$
P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}
$$

Definitions:
- Prior probability: $P(A)$, probability of $A$ without any other information.
- Likelihood: $P(B|A)$, probability of evidence $B$ given $A$.
- Posterior: $P(A|B)$, updated probability of $A$ after observing $B$.
- Evidence: $P(B)$, overall probability of $B$.

### 1.2 Naive Bayes Assumption
Features are conditionally independent given the class.
If $X = (x_1, x_2, ..., x_p)$ and class is $C_k$:
$$
P(C_k|X) = \frac{P(C_k) \cdot P(X|C_k)}{P(X)}
$$
Using independence:
$$
P(X|C_k) = \prod_{i=1}^{p} P(x_i|C_k)
$$
So the classifier uses:
$$
P(C_k|X) \propto P(C_k) \cdot \prod_{i=1}^{p} P(x_i|C_k)
$$

Decision rule:
$$
\hat{C} = \arg\max_k \left[ P(C_k) \cdot \prod_{i=1}^{p} P(x_i|C_k) \right]
$$

## 2. Naive Bayes Example (Concept)
Example features: Outlook, Temp, Humidity, Windy
Target: Play Tennis (Yes/No)

Steps:
1. Compute prior probabilities $P(Yes)$ and $P(No)$.
2. Compute likelihoods for each feature value given each class.
3. Multiply priors and likelihoods to get posterior (proportional) scores.
4. Choose the class with higher posterior score.

## 3. Confusion Matrix and Evaluation Metrics
Confusion matrix (binary case):

| Actual \ Predicted | Positive | Negative |
| --- | --- | --- |
| Positive | TP | FN |
| Negative | FP | TN |

Metrics:

Accuracy:
$$
Accuracy = \frac{TP + TN}{TP + TN + FP + FN}
$$

Error Rate:
$$
Error = \frac{FP + FN}{TP + TN + FP + FN} = 1 - Accuracy
$$

Precision:
$$
Precision = \frac{TP}{TP + FP}
$$

Recall:
$$
Recall = \frac{TP}{TP + FN}
$$

F1-Score:
$$
F1 = \frac{2 \cdot Precision \cdot Recall}{Precision + Recall}
$$

Support:
- Definition: number of actual samples for each class in the test set.
- It is a count, not a ratio.

Usage:
- Accuracy: overall correctness.
- Precision: reliability of positive predictions.
- Recall: how many actual positives are captured.

### 3.1 Classification Report Terms
- precision: $\frac{TP}{TP+FP}$ for each class.
- recall: $\frac{TP}{TP+FN}$ for each class.
- f1-score: harmonic mean of precision and recall.
- support: number of true instances for each class.

Macro average:
$$
	ext{Macro Avg} = \frac{1}{K} \sum_{k=1}^{K} \text{metric}_k
$$
Gives equal weight to each class.

Weighted average:
$$
	ext{Weighted Avg} = \frac{1}{N} \sum_{k=1}^{K} (\text{support}_k \cdot \text{metric}_k)
$$
Gives more weight to classes with more samples.

## 4. Algorithm (Iris Dataset)
```python
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.naive_bayes import GaussianNB
from sklearn.metrics import confusion_matrix, accuracy_score, precision_score, recall_score

# Step 1: Load dataset
csv_url = "https://archive.ics.uci.edu/ml/machine-learning-databases/iris/iris.data"
col_names = ["Sepal_Length", "Sepal_Width", "Petal_Length", "Petal_Width", "Species"]

df = pd.read_csv(csv_url, names=col_names)

# Step 2: Preprocessing
# Convert categorical target to numeric
# (Optional: use label encoding)

df["Species"] = df["Species"].astype("category").cat.codes

# Check missing values
print(df.isnull().sum())

# Split features and target
X = df.drop(["Species"], axis=1)
y = df["Species"]

# Train-test split
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=0
)

# Feature scaling (optional for Naive Bayes)
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

# Step 3: Train model
model = GaussianNB()
model.fit(X_train, y_train)

# Step 4: Predict
y_pred = model.predict(X_test)

# Step 5: Evaluate
cm = confusion_matrix(y_test, y_pred)
print(cm)
print("Accuracy:", accuracy_score(y_test, y_pred))
print("Precision:", precision_score(y_test, y_pred, average="micro"))
print("Recall:", recall_score(y_test, y_pred, average="micro"))
```
